Что можно рассчитать

  • Сессии психологов и стажёров: всего, по специалистам, по неделям и дням октября.
  • Новые обращения: число сделок и заявок, тип страницы, с которой пришла заявка, UTM-источник из адреса.
  • Промокоды: в таблицах психологов и стажёров, с датами.

Принятые допущения

  • Одна строка = одна сессия. Строка с покупкой пакета консультаций тоже считается одной записью (один пакет = одна строка) и на отдельные сессии не раскладывается.
  • Динамика строится по «Дате создания» записи: у части строк дата самой сессии не указана.
  • Объединены варианты написания одного специалиста (подтверждено): «настя осипова» → Анастасия Осипова, «Даша/Дарья Бахтеева», «Ксюша/Ксения Карпова», регистр букв («АННА СКОМОРОХ»).
  • Цены из выгрузки в отчёт не включены.

4. Новые обращения

Таблица новых клиентов · одна строка = одна сделка

С какой страницы пришла сделка

Если все заявки сделки пришли со страниц одного типа — сделка отнесена к нему; если с разных — «Несколько типов страниц»

Охват страниц

В скольких сделках встречается хотя бы одна заявка со страницы этого типа. Одна сделка может попасть в несколько строк, поэтому сумма больше

Источник привлечения (utm_source)

Метка utm_source из адресов заявок. Если метки нет — «Не указан»

Заявок в одной сделке

Сколько адресов «Lead from / Заявка с» записано в одной сделке

В таблице новых клиентов нет дат, поэтому динамику обращений по месяцам и неделям и изменения в структуре источников во времени построить нельзя. Тип страницы показывает, где человек оставил заявку, а не рекламный канал, через который он пришёл.

6. Выводы

Что показывают данные

    Ограничения анализа

    • Все таблицы содержат только октябрь 2026: помесячную динамику и сравнение с прошлым месяцем построить нельзя.
    • В таблице новых клиентов нет дат — нет динамики обращений и источников во времени.
    • utm_source есть только в адресах части заявок; у большинства сделок источник не указан. Тип страницы — это место заявки, а не канал привлечения.
    • Нет идентификаторов клиентов: уникальных и повторных клиентов не считали, записи между таблицами не сопоставляли.
    • Одна строка считается одной записью. 14 строк психологов — покупка пакета на 5 или 10 консультаций; каждая учтена как одна строка, сколько сессий из пакета уже проведено, по таблице не видно.
    • Динамика идёт по дате создания записи. Для 22 записей «на время» сессия назначена на другой день, в том числе на 2 ноября.
    • Причины изменений (реклама, сезонность, отпуска специалистов) по этим данным установить нельзя.
